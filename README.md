# NFC 키링 시연용 웹사이트 (블랙핑크 예시)

포레스트팩토리 제안용 시연 사이트입니다. NFC 키링을 태그했을 때 열리는 화면을 그대로 재현합니다.

## 실행 방법

Cursor에서 이 폴더를 열고 터미널에 아래 두 줄을 순서대로 입력하세요.

```
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 으로 접속합니다.

## 시연 흐름

| 순서 | 화면 | 내용 |
|---|---|---|
| 1 | 칩 인식 | 약 2초간 NFC를 읽는 연출 |
| 2 | 정품 인증 | 인증 완료 + 고유 번호 각인 + 발행 정보 |
| 3 | 소유 등록 | 등록 버튼을 누르면 소유자로 기록됩니다 |
| 4 | 인사 메시지 | 아티스트 음성 메시지 재생 화면 |
| 5 | 메인 | 뮤직비디오 · 비공개 포토 · 공식 채널 · 스토어 |

두 번째 방문부터는 1~4를 건너뛰고 바로 메인으로 들어가며, 상단에 **고유 번호와 함께한 날짜**가 표시됩니다.

화면 하단의 **처음부터 다시 시연** 버튼을 누르면 1번부터 다시 볼 수 있습니다. 실제 서비스에는 들어가지 않는 시연 전용 버튼입니다.

## 내용 수정하기

아티스트 이름, 링크, 번호, 사진 설명은 전부 아래 한 파일에 모여 있습니다.

```
src/lib/content.ts
```

다른 파일은 건드리지 않아도 됩니다.

## 사진과 음성 넣기

저작권 문제로 실제 이미지와 음성은 포함하지 않았습니다. 지금은 디자인된 플레이스홀더가 표시됩니다.

**사진 넣기**
1. `public/photos/` 폴더를 만들고 이미지를 넣습니다
2. `src/lib/content.ts` 의 `privatePhotos` 에서 `image: null` 을 `image: "/photos/01.jpg"` 로 바꿉니다

**음성 넣기**
1. `public/` 폴더에 음성 파일을 넣습니다
2. `src/lib/content.ts` 의 `welcomeMessage.audioSrc` 를 `"/welcome.mp3"` 로 바꿉니다

## 제안서 제출 전 확인할 것

- `src/lib/content.ts` 의 인스타그램 주소 — 공식 계정 URL 최종 확인 후 교체
- 실제 사진·음성은 기획사 제공 자산으로 교체 (사용 권한은 기획사에 있습니다)

## Cursor에 그대로 붙여넣을 수 있는 수정 프롬프트

색상 변경
```
src/app/globals.css 의 @theme 블록에서 --color-rose 값을 #원하는색 으로 바꿔줘
```

아티스트 교체
```
src/lib/content.ts 의 artist, keyring, musicVideo, socialLinks, store 값을 아래 정보로 교체해줘: (정보 입력)
```

비공개 포토 개수 변경
```
src/lib/content.ts 의 privatePhotos 배열을 6개로 늘리고 MainView 의 그리드는 2열 유지해줘
```

칩 인식 시간 조절
```
src/components/TagSequence.tsx 의 setTimeout 1900 값을 1200 으로 줄여줘
```

## 기술 구성

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4

소유 등록 정보는 브라우저 저장소에 기록됩니다. 실제 서비스에서는 서버에서 칩 고유값을 검증하는 구조로 바꿔야 합니다.

## 데모 모드

제안용으로 누구나 접속할 수 있게 하는 플래그입니다.

```
NEXT_PUBLIC_DEMO_MODE=true
```

켜면 태그 식별자 검증을 우회합니다. 주소를 직접 입력하거나 링크를 복사해
열어도 등록 화면으로 들어가고, 등록 버튼은 서버를 거치지 않습니다.

`false`로 바꾸면 정식 플로우로 돌아갑니다. 태그 URL(`/?tag=<식별자>`)로만
진입할 수 있고, 식별자가 없거나 발행 목록에 없으면 안내 화면이 나옵니다.
발행 목록은 `src/lib/tags.ts`에 있습니다.

로컬은 `.env.local`, 배포는 Vercel 프로젝트 환경변수에서 설정합니다.
