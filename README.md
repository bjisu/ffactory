# NFC 키링 시연용 웹사이트 (블랙핑크 예시)

포레스트팩토리 제안용 시연 사이트입니다. NFC 키링을 태그했을 때 열리는 화면을 그대로 재현합니다.

## 실행 방법

Cursor에서 이 폴더를 열고 터미널에 아래 두 줄을 순서대로 입력하세요.

```
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 으로 접속합니다.

## 시연 흐름

NFC 태그에 인코딩된 URL(`/?tag=<식별자>`)로 웹이 열리는 구조입니다. 브라우저가 칩을 직접 읽지 않습니다.

| 순서 | 화면 | 내용 |
|---|---|---|
| 1 | 등록하기 | 태그 URL 진입 후 정품 확인, 등록 버튼 하나 |
| 2 | 등록 완료 | 고유 번호 표시, 2초 뒤 자동 전환 |
| 3 | 메인 | 뮤직비디오 · 비공개 포토 · 공식 채널 · 스토어 |

등록하면 서버가 발급한 토큰이 브라우저에 저장됩니다. 같은 태그로 다시 들어오면 1~2를 건너뛰고 바로 메인으로 가며, 상단에 **고유 번호와 함께한 날짜**가 표시됩니다.

식별자가 없거나 발행 목록에 없으면 안내 화면으로 보냅니다. 단, 아래 **데모 모드**가 켜져 있으면 이 검증을 우회합니다.

화면 하단의 **처음부터 다시 시연** 버튼을 누르면 저장된 토큰을 지우고 1번부터 다시 볼 수 있습니다. 실제 서비스에는 들어가지 않는 시연 전용 버튼입니다.

## 이미 등록된 키링 화면

다른 사람이 이미 등록한 키링을 태그했을 때의 화면입니다. 정품 확인 표시는 그대로 두고 등록 버튼 대신 안내와 스토어 링크를 보여 줍니다. 비공개 포토와 메인으로는 넘어갈 수 없습니다.

시연에서는 `src/lib/content.ts` 의 `demoAlreadyRegistered` 를 `true` 로 바꾸거나, 화면 하단의 **등록된 키링 ON/OFF** 토글로 즉시 전환할 수 있습니다. 표시되는 등록일과 경과 일수는 같은 파일의 `demoRegistration` 값입니다.

실제 서비스에서는 이 값들이 아니라 **서버가 칩 번호별 등록 상태를 저장하고 응답**해서 동작합니다. 지금처럼 등록 정보를 브라우저에만 두면 다른 기기에서 태그했을 때 처음 태그한 것처럼 보이기 때문에, 재등록을 막으려면 서버 저장이 반드시 필요합니다. 이때 등록 정책(최초 1회 고정 / 소유권 이전 허용 / 조회만 개방)은 기술이 아니라 사업 판단 영역이며, 리셀 정책을 정한 뒤에 확정할 사안입니다.

## 데모 모드

제안용으로 누구나 접속할 수 있게 하는 플래그입니다.

```
NEXT_PUBLIC_DEMO_MODE=true
```

켜면 태그 식별자 검증을 우회합니다. 주소를 직접 입력하거나 링크를 복사해 열어도 등록 화면으로 들어가고, 등록 버튼은 서버를 거치지 않습니다.

`false`로 바꾸면 정식 플로우로 돌아갑니다. 검증 로직(`src/lib/tags.ts`, `src/app/api/tags/`)과 안내 화면(`src/components/InvalidTagScreen.tsx`)은 플래그와 무관하게 그대로 유지됩니다.

로컬은 `.env.local`, 배포는 Vercel 프로젝트 환경변수에서 설정합니다.

## 내용 수정하기

아티스트 이름, 링크, 번호, 사진 설명은 전부 아래 한 파일에 모여 있습니다.

```
src/lib/content.ts
```

발행된 태그 식별자 목록만 별도입니다.

```
src/lib/tags.ts
```

## 사진 교체하기

`public/photos/` 에 파일을 넣고 `src/lib/content.ts` 의 `privatePhotos` 에서 경로를 바꿉니다. 확장자가 png·webp여도 경로만 맞추면 됩니다. 파일이 없거나 경로가 틀리면 자동으로 플레이스홀더가 표시됩니다.

배경 사진은 두 장을 씁니다.

- `tagBackground` — 가로가 넓은 화면용 (현재 `bg.jpg`, 2100x2232)
- `tagBackgroundPortrait` — 세로가 긴 화면용 (현재 `bg-portrait.jpg`, 2100x4400)

배경을 교체하면 `src/components/StartScreen.tsx` 의 `aspect-[2100/2232]` 값도 새 이미지 비율로 함께 바꿔야 로고 위치가 맞습니다.

## 제안서 제출 전 확인할 것

- `src/lib/content.ts` 의 인스타그램 주소 — 공식 계정 URL 최종 확인 후 교체
- 실제 사진은 기획사 제공 자산으로 교체 (아티스트명·로고·초상 사용 권한 확인 필요)
- 외부 공개 전 데모 모드 플래그를 끌지 판단

## 기술 구성

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4

태그 검증과 토큰 발급은 `src/app/api/tags/` 의 라우트에서 처리합니다. 데이터베이스가 없어 발행 목록은 `src/lib/tags.ts` 에 코드로 두었고, 등록 증명은 HMAC 토큰 자체에 의존합니다. 실제 서비스에서는 발행 목록과 등록 이력을 DB로 옮기고 토큰에 만료·폐기를 붙여야 합니다.
